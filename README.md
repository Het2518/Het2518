## 🏋️ GymSense AI — Intelligent Fitness Analytics

> **Deep Learning × Sensor Analytics × Generative AI**

A full-stack AI fitness analytics system that converts raw wearable sensor telemetry into **exercise recognition, repetition tracking, tempo analysis, and personalized AI coaching**.

* Tempo quality scoring
* Real-time synthetic sensor simulation

## 🦈 Shark Tank Investment Intelligence

> **Classification × Regression × Multi-label Learning**

A multi-task ML pipeline for analyzing historical Shark Tank pitches.

Rather than solving only one prediction problem, the project explores **three separate ML tasks**.

### 🎯 ML Tasks

**1. Deal Prediction**

Predict whether a startup receives an investment.

Best model:
`Gradient Boosting`

* Accuracy: **62.0%**
* F1: **0.663**
* ROC-AUC: **0.645**

**2. Valuation Prediction**

Predict expected deal valuation for successful pitches.

Best model:
`Lasso Regression`

* R²: **0.7737**

**3. Investor Prediction**

Multi-label classification for estimating which individual sharks are likely to invest.

### 🛠 Stack

`Python` `Pandas` `Scikit-Learn` `Gradient Boosting` `Lasso` `Jupyter`
